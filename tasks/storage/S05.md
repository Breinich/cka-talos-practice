# S05 — Expand and verify a volume claim

| Field | Value |
|---|---|
| Task ID | `S05` |
| CKA pillar | `storage` |
| Mode | `conditional` |
| Capability | `expandable` |
| Points | 2 |

## Task

Only when a detected class advertises expansion, create `expandable-claim`, request a safe size increase, verify capacity/filesystem behavior, and record it in `S05.txt`. Otherwise document the unsupported reason; never shrink a claim.

## Safety boundary

Attempt this only when `.lab/capabilities.env` reports `EXPANDABLE=true`. Otherwise the scorer reports `SKIP`.

## Validation

From the repository root:

```bash
./scripts/validate.sh --task S05
./scripts/validate.sh --task S05 --json
```

The result is `SKIP` when the capability is absent; otherwise the two supported criteria are scored independently. Answers and hints remain separate under `answers/`.
