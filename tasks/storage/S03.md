# S03 — Provision a dynamic PVC

| Field | Value |
|---|---|
| Task ID | `S03` |
| CKA pillar | `storage` |
| Mode | `conditional` |
| Capability | `storageclass` |
| Points | 2 |

## Task

If detected, create `dynamic-claim` using the default class and verify it becomes Bound after use. Do not modify the class.

## Safety boundary

Attempt this only when `.lab/capabilities.env` reports `STORAGECLASS=true`. Otherwise the scorer reports `SKIP`.

## Validation

From the repository root:

```bash
./scripts/validate.sh --task S03
./scripts/validate.sh --task S03 --json
```

The result is `SKIP` when the capability is absent; otherwise the two supported criteria are scored independently. Answers and hints remain separate under `answers/`.
