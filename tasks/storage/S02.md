# S02 — Model a static PV and PVC safely

| Field | Value |
|---|---|
| Task ID | `S02` |
| CKA pillar | `storage` |
| Mode | `simulation` |
| Capability | `core` |
| Points | 3 |

## Task

Write `.lab/evidence/S02-static.yaml` containing a valid, explicitly bound static PV plus PVC `static-claim` and a consuming Pod. Label the PV with lab ownership and active prefix, then client-dry-run the file but do not apply it. Talos has no assumed safe node path or static backend; practice live binding only in a disposable lab with a known-empty volume.

## Safety boundary

Create only the requested local artifact under `.lab/evidence/`; do not apply simulated resources unless the task explicitly says it is safe.

## Validation

From the repository root:

```bash
./scripts/validate.sh --task S02
./scripts/validate.sh --task S02 --json
```

The validator evaluates two independent criteria and returns `PASS`, `PARTIAL`, or `FAIL` without printing a solution. Answers and hints remain separate under `answers/`.
