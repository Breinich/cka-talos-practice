# A07 — Render and inspect a Helm release

| Field | Value |
|---|---|
| Task ID | `A07` |
| CKA pillar | `architecture` |
| Mode | `simulation` |
| Capability | `helm` |
| Points | 2 |

## Task

Without installing anything, use `helm template` on a locally chosen or already downloaded chart. Save output as `A07-rendered.yaml` and identify values/release/namespace flags. If Helm is absent this is `UNSUPPORTED`.

## Safety boundary

Create only the requested local artifact under `.lab/evidence/`; do not apply simulated resources unless the task explicitly says it is safe.

## Validation

From the repository root:

```bash
./scripts/validate.sh --task A07
./scripts/validate.sh --task A07 --json
```

The validator evaluates two independent criteria and returns `PASS`, `PARTIAL`, or `FAIL` without printing a solution. Answers and hints remain separate under `answers/`.
