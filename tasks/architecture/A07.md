# A07 — Render a local release without installing it

| Field | Value |
|---|---|
| Task ID | `A07` |
| CKA pillar | `architecture` |
| Mode | `simulation` |
| Capability | `helm` |
| Points | 2 |

## Scenario and objective

The bundled chart `samples/architecture/chart` defaults to one relay replica. With Helm installed, render release `harbor-relay` into `.lab/evidence/A07-rendered.yaml` using `helm template` in the active namespace and override replicas to 2. The resulting Deployment must carry the release-derived name, namespace, two replicas, and the bundled container image. Do not use `helm install` or apply this render.

The active namespace is `CKA_LAB_NAMESPACE` (default `cka-practice`); the active prefix is `CKA_LAB_PREFIX` (default `cka-practice`). If setup used flags, export matching `CKA_LAB_PREFIX` and `CKA_LAB_NAMESPACE` before validation; `.lab/state.env` records their values.

## Safety boundary

Local artifacts only; never apply cluster-scoped definitions or rendered components. All created cluster objects require `cka-lab.io/owner=cka-talos-practice`. Never commit `.lab/evidence` or credentials.

./scripts/validate.sh --task A07
