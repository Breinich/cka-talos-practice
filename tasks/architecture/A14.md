# A14 — Inspect certificate lifetimes

| Field | Value |
|---|---|
| Task ID | `A14` |
| CKA pillar | `architecture` |
| Mode | `read-only` |
| Capability | `core` |
| Points | 2 |

## Task

Inspect the Kubernetes API certificate presented by the configured server and/or Talos certificate status; record issuer and expiry evidence in `A14.txt`. Never copy private keys.

## Safety boundary

Observation only: do not patch cluster resources, restart services, or alter Talos machine configuration.

## Validation

From the repository root:

```bash
./scripts/validate.sh --task A14
./scripts/validate.sh --task A14 --json
```

The validator evaluates two independent criteria and returns `PASS`, `PARTIAL`, or `FAIL` without printing a solution. Answers and hints remain separate under `answers/`.
