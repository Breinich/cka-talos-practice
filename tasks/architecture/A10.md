# A10 — Inspect Talos machine and service health

| Field | Value |
|---|---|
| Task ID | `A10` |
| CKA pillar | `architecture` |
| Mode | `read-only` |
| Capability | `talosctl` |
| Points | 2 |

## Task

With `talosctl`, inspect service health for kubelet/containerd and machine health; save non-secret output in `A10.txt`. Do not use `talosctl apply-config`, reboot, reset, or service restart.

## Safety boundary

Observation only: do not patch cluster resources, restart services, or alter Talos machine configuration.

## Validation

From the repository root:

```bash
./scripts/validate.sh --task A10
./scripts/validate.sh --task A10 --json
```

The validator evaluates two independent criteria and returns `PASS`, `PARTIAL`, or `FAIL` without printing a solution. Answers and hints remain separate under `answers/`.
