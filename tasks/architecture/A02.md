# A02 — Build and use a minimal kubeconfig

| Field | Value |
|---|---|
| Task ID | `A02` |
| CKA pillar | `architecture` |
| Mode | `live` |
| Capability | `core` |
| Points | 3 |

## Task

Create `.lab/evidence/A02.kubeconfig`, limited to this cluster/context and an identity that can get Pods in the lab namespace. Use a short-lived ServiceAccount token; do not copy an administrator credential. Verify it.

## Safety boundary

Work only in the configured lab namespace. Label created resources with `cka-lab.io/owner=cka-talos-practice`.

## Validation

From the repository root:

```bash
./scripts/validate.sh --task A02
./scripts/validate.sh --task A02 --json
```

The validator evaluates two independent criteria and returns `PASS`, `PARTIAL`, or `FAIL` without printing a solution. Answers and hints remain separate under `answers/`.
