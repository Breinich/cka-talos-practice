# A18 — Render a cluster component with Helm or Kustomize

| Field | Value |
|---|---|
| Task ID | `A18` |
| CKA pillar | `architecture` |
| Mode | `simulation` |
| Capability | `core` |
| Points | 2 |

## Task

Choose a cluster component such as Metrics Server or an ingress controller. Render its configured manifests offline with `helm template` when Helm is available or with a Kustomize base/overlay otherwise. Save the rendered workload as `.lab/evidence/A18-component.yaml` and sanitized render/configuration commands plus values, overlay, or patch choices as `.lab/evidence/A18.txt`. Do not install the component or apply the rendered output.

## Safety boundary

Rendering only. Do not modify `kube-system`, CRDs, admission, controllers, cluster roles, or shared networking on the homelab.

## Validation

From the repository root:

```bash
./scripts/validate.sh --task A18
./scripts/validate.sh --task A18 --json
```

The validator checks the rendered component and its configuration evidence independently and returns `PASS`, `PARTIAL`, or `FAIL` without printing a solution. Answers and hints remain separate under `answers/`.
