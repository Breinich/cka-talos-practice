# A09 — Inspect control-plane components

| Field | Value |
|---|---|
| Task ID | `A09` |
| CKA pillar | `architecture` |
| Mode | `read-only` |
| Capability | `core` |
| Points | 2 |

## Task

Identify API server, scheduler, controller manager, and etcd instances and their placement; save commands/output in `A09.txt`. Do not edit static pods.

## Safety boundary

Observation only: do not patch cluster resources, restart services, or alter Talos machine configuration.

## Validation

From the repository root:

```bash
./scripts/validate.sh --task A09
./scripts/validate.sh --task A09 --json
```

The validator evaluates two independent criteria and returns `PASS`, `PARTIAL`, or `FAIL` without printing a solution. Answers and hints remain separate under `answers/`.
