# N11 — Compare Service types safely

| Field | Value |
|---|---|
| Task ID | `N11` |
| CKA pillar | `networking` |
| Mode | `simulation` |
| Capability | `core` |
| Points | 2 |

## Task

Write `.lab/evidence/N11-services.yaml` containing valid, ownership-labelled NodePort and ExternalName Service examples, and client-dry-run them. Do not apply them: NodePort can expose a homelab workload and a LoadBalancer can allocate shared infrastructure.

## Safety boundary

Create only the requested local artifact under `.lab/evidence/`; do not apply simulated resources unless the task explicitly says it is safe.

## Validation

From the repository root:

```bash
./scripts/validate.sh --task N11
./scripts/validate.sh --task N11 --json
```

The validator evaluates two independent criteria and returns `PASS`, `PARTIAL`, or `FAIL` without printing a solution. Answers and hints remain separate under `answers/`.
