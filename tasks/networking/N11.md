## Scenario

Write `.lab/evidence/N11-services.yaml` with two owned Services in the configured namespace, then run a local/client dry-run only. `estuary-node-demo` models a NodePort for the API selector at Service port 8080, named HTTP target and nodePort 30081. `estuary-alias-demo` models an ExternalName alias to `estuary.lab.invalid`.

## Expected state

Outcome: both types, ownership/scope, and exact mapping are checked independently. Do not apply the manifests: a NodePort may expose a homelab workload, and this exercise does not provision an external endpoint.

## Safety boundary

Local artifact only under `.lab/evidence/`; do not apply it or alter cluster/system resources. The validator reads it offline.
