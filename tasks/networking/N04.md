# N04 — Validate cluster DNS

| Field | Value |
|---|---|
| Task ID | `N04` |
| CKA pillar | `networking` |
| Mode | `live` |
| Capability | `core` |
| Points | 2 |

## Task

From `toolbox`, test short, namespace-qualified, and cluster-qualified Service DNS names. Save names and returned addresses in `N04.txt`.

## Safety boundary

Work only in the configured lab namespace. Label created resources with `cka-lab.io/owner=cka-talos-practice`.

## Validation

From the repository root:

```bash
./scripts/validate.sh --task N04
./scripts/validate.sh --task N04 --json
```

The validator evaluates two independent criteria and returns `PASS`, `PARTIAL`, or `FAIL` without printing a solution. Answers and hints remain separate under `answers/`.
