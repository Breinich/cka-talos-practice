# N07 — Create Gateway API routing

| Field | Value |
|---|---|
| Task ID | `N07` |
| CKA pillar | `networking` |
| Mode | `conditional` |
| Capability | `gateway` |
| Points | 2 |

## Task

If Gateway CRDs and a usable Gateway exist, attach HTTPRoute `web-route` to an allowed listener and route to `web`. Do not create a cluster-scoped GatewayClass.

## Safety boundary

Attempt this only when `.lab/capabilities.env` reports `GATEWAY=true`. Otherwise the scorer reports `SKIP`.

## Validation

From the repository root:

```bash
./scripts/validate.sh --task N07
./scripts/validate.sh --task N07 --json
```

The result is `SKIP` when the capability is absent; otherwise the two supported criteria are scored independently. Answers and hints remain separate under `answers/`.
