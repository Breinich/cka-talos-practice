# N06 — Create an Ingress rule

| Field | Value |
|---|---|
| Task ID | `N06` |
| CKA pillar | `networking` |
| Mode | `conditional` |
| Capability | `ingress` |
| Points | 2 |

## Task

If an IngressClass exists, create `web-ingress` routing a test hostname/path to `web`; do not alter controller configuration or public DNS.

## Safety boundary

Attempt this only when `.lab/capabilities.env` reports `INGRESS=true`. Otherwise the scorer reports `SKIP`.

## Validation

From the repository root:

```bash
./scripts/validate.sh --task N06
./scripts/validate.sh --task N06 --json
```

The result is `SKIP` when the capability is absent; otherwise the two supported criteria are scored independently. Answers and hints remain separate under `answers/`.
