# N05 — Enforce default deny and allow rules

| Field | Value |
|---|---|
| Task ID | `N05` |
| CKA pillar | `networking` |
| Mode | `conditional` |
| Capability | `networkpolicy` |
| Points | 3 |

## Task

Only if setup reports enforcement support, create `default-deny` with both ingress and egress isolation and least-privilege `allow-web` with explicit ingress and egress rules; verify one allowed and one denied flow and save sanitized results in `.lab/evidence/N05.txt`. Do not assume API presence proves enforcement.

## Safety boundary

Attempt this only when `.lab/capabilities.env` reports `NETWORKPOLICY=true`. Otherwise the scorer reports `SKIP`.

## Validation

From the repository root:

```bash
./scripts/validate.sh --task N05
./scripts/validate.sh --task N05 --json
```

The result is `SKIP` when the capability is absent; otherwise the two supported criteria are scored independently. Answers and hints remain separate under `answers/`.
