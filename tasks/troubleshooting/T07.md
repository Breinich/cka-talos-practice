# T07 — Use events and describe

| Field | Value |
|---|---|
| Task ID | `T07` |
| CKA pillar | `troubleshooting` |
| Mode | `live` |
| Capability | `core` |
| Points | 2 |

## Task

Use `describe`, sorted events, reasons and messages to explain one seeded failure before fixing it; save evidence in `T07.txt`.

## Safety boundary

Work only in the configured lab namespace. Label created resources with `cka-lab.io/owner=cka-talos-practice`.

## Validation

From the repository root:

```bash
./scripts/validate.sh --task T07
./scripts/validate.sh --task T07 --json
```

The validator evaluates two independent criteria and returns `PASS`, `PARTIAL`, or `FAIL` without printing a solution. Answers and hints remain separate under `answers/`.
