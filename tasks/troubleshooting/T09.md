# T09 — Assess node conditions and capacity

| Field | Value |
|---|---|
| Task ID | `T09` |
| CKA pillar | `troubleshooting` |
| Mode | `read-only` |
| Capability | `core` |
| Points | 2 |

## Task

Assess all node conditions, taints, capacity/allocatable and pressure signals in `T09.txt`. Do not drain, cordon or label nodes.

## Safety boundary

Observation only: do not patch cluster resources, restart services, or alter Talos machine configuration.

## Validation

From the repository root:

```bash
./scripts/validate.sh --task T09
./scripts/validate.sh --task T09 --json
```

The validator evaluates two independent criteria and returns `PASS`, `PARTIAL`, or `FAIL` without printing a solution. Answers and hints remain separate under `answers/`.
