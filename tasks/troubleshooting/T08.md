# T08 — Inspect resource usage

| Field | Value |
|---|---|
| Task ID | `T08` |
| CKA pillar | `troubleshooting` |
| Mode | `conditional` |
| Capability | `metrics` |
| Points | 2 |

## Task

Use `kubectl top` for nodes and namespaced Pods, identify CPU and memory units, and save sanitized output in `T08.txt`.

## Safety boundary

Attempt this only when `.lab/capabilities.env` reports `METRICS=true`. Otherwise the scorer reports `SKIP`.

## Validation

From the repository root:

```bash
./scripts/validate.sh --task T08
./scripts/validate.sh --task T08 --json
```

The result is `SKIP` when the capability is absent; otherwise the two supported criteria are scored independently. Answers and hints remain separate under `answers/`.
