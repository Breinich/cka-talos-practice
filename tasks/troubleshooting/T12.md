# T12 — Debug with an ephemeral container

| Field | Value |
|---|---|
| Task ID | `T12` |
| CKA pillar | `troubleshooting` |
| Mode | `live` |
| Capability | `core` |
| Points | 2 |

## Task

Use `kubectl debug` with an ephemeral container against a lab Pod, inspect shared network/process context, exit, and save the command plus observation in `T12.txt`. Do not target host namespaces or nodes.

## Safety boundary

Work only in the configured lab namespace. Label created resources with `cka-lab.io/owner=cka-talos-practice`.

## Validation

From the repository root:

```bash
./scripts/validate.sh --task T12
./scripts/validate.sh --task T12 --json
```

The validator evaluates two independent criteria and returns `PASS`, `PARTIAL`, or `FAIL` without printing a solution. Answers and hints remain separate under `answers/`.
