# W01 — Create a Deployment with resources

| Field | Value |
|---|---|
| Task ID | `W01` |
| CKA pillar | `workloads` |
| Mode | `live` |
| Capability | `core` |
| Points | 2 |

## Task

Create Deployment `resource-app` with CPU/memory requests and limits, two replicas, and the ownership label.

## Safety boundary

Work only in the configured lab namespace. Label created resources with `cka-lab.io/owner=cka-talos-practice`.

## Validation

From the repository root:

```bash
./scripts/validate.sh --task W01
./scripts/validate.sh --task W01 --json
```

The validator evaluates two independent criteria and returns `PASS`, `PARTIAL`, or `FAIL` without printing a solution. Answers and hints remain separate under `answers/`.
