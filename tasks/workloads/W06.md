# W06 — Create a StatefulSet with stable identity

| Field | Value |
|---|---|
| Task ID | `W06` |
| CKA pillar | `workloads` |
| Mode | `live` |
| Capability | `core` |
| Points | 2 |

## Task

Create headless Service and StatefulSet, both `ordered-app`, with stable network identity and at least two replicas. Do not require persistent storage.

## Safety boundary

Work only in the configured lab namespace. Label created resources with `cka-lab.io/owner=cka-talos-practice`.

## Validation

From the repository root:

```bash
./scripts/validate.sh --task W06
./scripts/validate.sh --task W06 --json
```

The validator evaluates two independent criteria and returns `PASS`, `PARTIAL`, or `FAIL` without printing a solution. Answers and hints remain separate under `answers/`.
