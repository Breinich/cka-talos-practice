# W08 — Apply node affinity and pod anti-affinity

| Field | Value |

## Task

Create Deployment `affinity-app` using required or preferred node affinity plus preferred pod anti-affinity. It must remain schedulable on this cluster.

## Safety boundary

Work only in the configured lab namespace. Label created resources with `cka-lab.io/owner=cka-talos-practice`.

## Validation

From the repository root:

```bash
./scripts/validate.sh --task W08
./scripts/validate.sh --task W08 --json
```

The validator evaluates two independent criteria and returns `PASS`, `PARTIAL`, or `FAIL` without printing a solution. Answers and hints remain separate under `answers/`.
