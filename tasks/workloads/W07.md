# W07 — Use ConfigMap and Secret projections

| Field | Value |
|---|---|
| Task ID | `W07` |
| CKA pillar | `workloads` |
| Mode | `live` |
| Capability | `core` |

## Task

Create ConfigMap `app-config`, Secret `app-secret` with a dummy value, and Pod `config-consumer` consuming both via environment and/or volumes. Do not expose decoded Secret data.

## Safety boundary

Work only in the configured lab namespace. Label created resources with `cka-lab.io/owner=cka-talos-practice`.

## Validation

From the repository root:

```bash
./scripts/validate.sh --task W07
./scripts/validate.sh --task W07 --json
```

The validator evaluates two independent criteria and returns `PASS`, `PARTIAL`, or `FAIL` without printing a solution. Answers and hints remain separate under `answers/`.
