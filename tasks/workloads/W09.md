# W09 — Use taints and tolerations safely

| Field | Value |
|---|---|
| Task ID | `W09` |
| CKA pillar | `workloads` |
| Mode | `live` |
| Capability | `core` |
| Points | 2 |

## Task

Without changing node taints, create Pod `tolerant-app` with a meaningful toleration and record the matching taint/NoSchedule reasoning in `W09.txt`.

## Safety boundary

Work only in the configured lab namespace. Label created resources with `cka-lab.io/owner=cka-talos-practice`.

## Validation

From the repository root:

```bash
./scripts/validate.sh --task W09
./scripts/validate.sh --task W09 --json
```

The validator evaluates two independent criteria and returns `PASS`, `PARTIAL`, or `FAIL` without printing a solution. Answers and hints remain separate under `answers/`.
