# W03 — Roll back a Deployment

| Field | Value |
|---|---|
| Task ID | `W03` |
| CKA pillar | `workloads` |
| Mode | `live` |
| Capability | `core` |
| Points | 2 |

## Task

Introduce a bad revision in `rollout-app`, identify it, roll back, and leave the Deployment healthy with revision history.

## Safety boundary

Work only in the configured lab namespace. Label created resources with `cka-lab.io/owner=cka-talos-practice`.

## Validation

From the repository root:

```bash
./scripts/validate.sh --task W03
./scripts/validate.sh --task W03 --json
```

The validator evaluates two independent criteria and returns `PASS`, `PARTIAL`, or `FAIL` without printing a solution. Answers and hints remain separate under `answers/`.
