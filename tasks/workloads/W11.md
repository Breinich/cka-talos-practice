# W11 — Use probes and security context

| Field | Value |
|---|---|
| Task ID | `W11` |
| CKA pillar | `workloads` |
| Mode | `live` |
| Capability | `core` |
| Points | 2 |

## Task

Create Pod `hardened-app` with readiness/startup or liveness probes, non-root execution where image-compatible, and `allowPrivilegeEscalation: false`.

## Safety boundary

Work only in the configured lab namespace. Label created resources with `cka-lab.io/owner=cka-talos-practice`.

## Validation

From the repository root:

```bash
./scripts/validate.sh --task W11
./scripts/validate.sh --task W11 --json
```

The validator evaluates two independent criteria and returns `PASS`, `PARTIAL`, or `FAIL` without printing a solution. Answers and hints remain separate under `answers/`.
