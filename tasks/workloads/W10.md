# W10 — Configure an HPA

| Field | Value |
|---|---|
| Task ID | `W10` |
| CKA pillar | `workloads` |
| Mode | `conditional` |
| Capability | `metrics` |
| Points | 2 |

## Task

Create HPA `web-hpa` targeting Deployment `web`, CPU utilization, minimum 1 and maximum at least 2 replicas.

## Safety boundary

Attempt this only when `.lab/capabilities.env` reports `METRICS=true`. Otherwise the scorer reports `SKIP`.

## Validation

From the repository root:

```bash
./scripts/validate.sh --task W10
./scripts/validate.sh --task W10 --json
```

The result is `SKIP` when the capability is absent; otherwise the two supported criteria are scored independently. Answers and hints remain separate under `answers/`.
